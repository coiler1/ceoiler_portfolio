# ceoiler_portfolio

Goal of this portfolio is to allow Hopkins student athletes a better way to access in game photos.
This portfolio consists of pages where athletes can view my work and recent games/events I have photographed and then contact me to get specific links to photos. In addition I added an image search functionality that uses
and AI model to take natural language queries and map them to specific images. The current iteration of the website can be viewed at https://ceoiler-portfolio.onrender.com
